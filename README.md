# Quittr Dashboard

这是一个可在自己的电脑上运行的多用户 Quittr 应用。用户注册登录后，日记、Melius 会话、恢复记录、课程和游戏进度会保存到这台电脑的 SQLite 数据库中，同一账号可跨设备继续使用。

## 技术栈

- 前端：原生 HTML/CSS/JS + React 18 UMD
- 后端：原生 Node.js `http` 服务
- 数据存储：SQLite（Node.js 内置 `node:sqlite`），账号、会话、日记、聊天和社区分别建表
- 身份认证：scrypt 密码哈希、服务端持久化会话、HttpOnly Cookie、请求来源校验和登录限流
- iPhone：安全区、键盘和触控适配；支持添加到主屏幕。另提供 [iOS App 工程](ios/README.md)，连接相同服务器。

## 本地启动

### 1. 启动服务

```bash
npm start
```

### 2. 打开页面

```text
http://localhost:3000
```

需要 Node.js **24.13.x 或更新的 24.x**，无 npm 运行时依赖。使用 `npm start` 启动，`npm test` 运行测试。页面会先显示登录/注册入口。

默认监听 `0.0.0.0:3000`，同一局域网的其他设备可访问 `http://这台电脑的局域网IP:3000`。`PORT` 可更换端口。外网域名、HTTPS、Mac 常驻服务、备份和管理员操作见 [部署说明](DEPLOYMENT.md)。

现有 `data/quittr-state.json` 不会被自动归入任何用户，也不会再被服务读写。旧数据可通过管理员命令明确导入到指定新账号。

### AI 聊天配置

在项目根目录的 `.env` 中配置 `DASHSCOPE_API_KEY`、`DASHSCOPE_BASE_URL` 和 `MELIUS_MODEL`，字段示例见 `.env.example`。当前使用阿里云 Coding Plan 的 OpenAI 兼容接口与 `qwen3.7-plus` 模型。更改配置后需重启服务。

密钥仅由 Node.js 服务端读取；前端通过 `/api/melius/chat` 发起聊天请求，不接触密钥。`.env` 已被 Git 忽略。

Melius 可调用应用内小游戏，并把用户明确表达的日记、动力、未破戒打卡及破戒复盘保存到当前账号的数据库。每次归档会显示结果卡片，可直接查看日记、动力或统计。破戒只有在用户明确说明已经发生时才记录；假设、担心、差点破戒不应重置统计。

Melius 会根据对话生成行动计划、知识解读和轻量复盘卡片，内容由模型通过 `present_card` 结构化输出。卡片可选一个尝试步骤、复制或继续讨论；步骤选择仅是当前界面的意向，不会写成打卡。建议卡与已保存记录使用不同样式，卡片可在最终文字回复前出现，并随完整会话保存到服务器。

Melius 回复通过 SSE 流式传输，文字随模型生成逐段显示；工具参数不会展示，工具执行后才显示对应结果。中断的部分回复会标明不完整，重新发送会沿用原消息 ID，避免重复归档。点击「停止输出」停止客户端接收；服务端已执行的记录会保留，重试可取回最终回复。旧的非流式 JSON 调用继续兼容。

聊天消息保存在当前账号的数据库中，刷新、换设备或服务重启后均可恢复。历史按页加载，离开小游戏后可以继续原对话。未收到回复的消息可重新发送；消息ID和已执行操作会持久化，超时或刷新后重试不会重复记录。同一消息处理中点击“停止等待”只停止前端等待，已经执行的记录会在重试时取回。

麦克风按钮使用浏览器的 SpeechRecognition 接口，点击后才启动语音识别，识别结果先填入输入框供编辑，不会自动发送。可用性取决于浏览器、麦克风权限及语音识别网络服务；不支持时可使用系统听写或键盘输入。

测试：`npm test`。设置 `QUITTR_DATA_DIR` 可使用独立的数据目录验证，避免把测试事件写入实际记录。

## Melius 每日小课堂

首页和 Library 会主动展示当天的小课堂，Learn 中可切换「为你推荐」与原有系统课程。应用按浏览器时区选取用户真实记录（Melius 对话、日记、冲动、恢复打卡和小课反馈），调用 coding plan 的 `qwen3.7-plus` 生成五张中文卡片：理解、过程图、练习、自我觉察、今日行动。

素材窗口按「昨天 → 最近 14 天 → 最近 90 天 → 更早的记录」逐级放宽，只要有任何一条记录，课程就一定基于真实素材个性化生成，不会退回固定内容；没有记录时才是觉察入门课。提示词要求模型抓住素材里的具体场景、感受或触发点，避免写成通用通稿。

课程每天首次打开时自动准备，**只要当天还没有 AI 生成的课程就会生成**——包括此前展示过或已完成过的「精选小课」，它会被替换成真正的个性化课程，原课程留在历史里。生成成功后按日期和时区保存，重复访问不会重复调用模型。首页「重新生成」或阅读页「换一节」会明确发起新的 AI 请求：换教学重点、换比喻、重写全部卡片；原课程及完成记录仍保留在历史中。生成失败时自动重试一次（换一个温度），仍失败则保留原课程并提示重试，不将固定内容伪装为 AI 生成。

模型失败时保留标为「精选小课」的内容并允许重试。新增 Melius 消息会在服务端保存用户原文，用于次日课程；升级前未保存原文的对话仍可通过已归档的日记等记录提供依据。原文保存在这台服务器的当前账号数据库中，并通过已配置的模型接口用于课程生成，不返回给课程展示页。

课程模型通过 `LESSON_MODEL`（默认跟随 `MELIUS_MODEL`，即 `qwen3.7-plus`）、超时通过 `LESSON_TIMEOUT_MS`（默认 60 秒）配置，复用 `DASHSCOPE_API_KEY` 与 `DASHSCOPE_BASE_URL`。

新增接口：`GET /api/lessons/daily?timeZone=Asia%2FShanghai` 获取今日课程及历史；`POST /api/lessons/daily` 生成并缓存课程；`POST /api/lessons/complete` 保存完成记录与选择。测试使用独立内存状态，不修改实际恢复记录。

## 当前功能

- 首页恢复进度、里程碑、快捷操作和功能卡片
- Pledge 弹窗与完成动画
- Analytics 页面，展示当前 streak、历史 reset、趋势图和统计指标
- Reset 按钮会写入一次 relapse 记录，并刷新统计数据
- Library 页面，包含声音场景、课程、游戏和排行榜原型
- Profile 页面，显示真实账号信息、统计、数据导出、修改密码和退出登录
- 多用户社区，支持真实帖子、评论和独立点赞，不显示用户邮箱
- 注册、登录、30 天登录会话、账号隔离及管理员密码重置
- Melius 聊天页：多轮对话、小游戏调用、日记与动力归档、语音输入及失败重试
- 底部导航，可在 Home、Chat、Stats、Library 和 Profile 之间切换

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/` | Quittr Dashboard 页面 |
| `GET` | `/api/quittr/analytics` | 获取恢复统计数据 |
| `POST` | `/api/quittr/relapses` | 记录一次 relapse/reset 并返回新统计 |
| `POST` | `/api/melius/chat` | 对话、应用工具调用及按消息ID去重的重试 |

## 数据与账号

- `data/quittr.sqlite` 是正式数据库；SQLite 的 WAL 文件也属于运行数据，不提交 Git。
- 日记、聊天轮次、恢复统计、小课堂、课程完成、游戏进度和 blocker 偏好按 `user_id` 隔离。每个聊天轮次保存用户原文、完整回复、卡片、重试上下文及工具去重记录。
- 新账号从零开始，既不继承旧 Demo 的恢复记录，也不显示预置社区帖子。
- 私人 API 必须登录；服务端从 Cookie 解析用户，客户端无法指定其他用户的数据归属。社区是登录用户共享的公开空间，日记和聊天不会自动发布到社区。
- `npm run backup` 生成一致性的在线数据库备份。`npm run admin -- users` 查看账号，`npm run admin -- reset-password user@example.com` 重置密码并注销该账号全部会话。
- 登录后的「我的账号」支持下载个人数据。尚未接入邮件服务，邮箱作为登录标识，不发送验证邮件；忘记密码由管理员重置。

## 注意事项

- 使用 Node.js 24.13+ 的 24.x 版本，依赖内置 SQLite；当前 Node 版本可能输出 SQLite 实验性提示。
- React 18 从项目内 `public/vendor/` 加载；界面字体有外部 Google Fonts 请求，字体不可达时使用系统字体。
- `npm test` 包含工具调用、记录去重、破戒识别边界、重发和语音转文字逻辑的回归测试。
