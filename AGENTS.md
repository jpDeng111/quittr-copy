# Project workflow

After completing a user-requested task, run the relevant checks, create a Git commit whose title summarizes the core change, and push it to the current GitHub branch. This workflow was explicitly requested by the user. Keep distinct completed tasks in separate commits when practical.

Stage only changes belonging to the task. Preserve unrelated work already present in the workspace. Never commit secrets, local databases, exports, personal records, or ignored generated files. Report the commit and push result accurately, and distinguish automated checks from real-device verification.
