# QUITTR 商业应用逆向分析报告（产品级 OSINT 逆向）

> 逆向对象：QUITTR（quittrapp.com）— iOS / Android / Chrome 三端"戒色恢复"商业 App
> 分析日期：2026-10-25
> 方法：官网与其 SEO 对比页、App Store / Google Play 公开信息、第三方 UI 拆站（screensdesign）、媒体报道与社区讨论的交叉验证。无源码、无抓包，属于**外部行为推断**，与代码级逆向置信度不同。

## 1. 产品定位一句话

用**游戏化 + 社区 + 危机干预工具**包装的成人内容戒断管理 App，卖点是"不监控你、不告密给你的伴侣/家人，只帮你自己"，商业模式为纯订阅（无免费版）。

基本盘（公开口径）：开发商 **Quittr, LLC**，英国两位年轻创始人 **Alex Slater**（报道称 19–20 岁）与 **Connor McLaren**（21–23 岁）的二人生意，404 Media 报道其营收约 **$500K/月**（第三方媒体口径）。iOS 18+ 分级、Health & Fitness 类，约 3.4–4 万评分、4.7 星，100 万+ 下载；官网宣称 2M+ 用户、"62% 成功率"（该成功率为营销口径，无方法学说明）。

## 3. 商业化逆向（收入结构拆解）

| 档位 | 价格（2026-10 公开口径） | 设计意图 |
|---|---|---|
| 月付 | $9.99–14.99（美区 App Store 曾见 $37.99 高价档，疑为不同权益包） | 锚定用，几乎不期望成交 |
| 年付 | $109.96/年，1 天免费试用 | 主力 SKU（折算 ~$9.16/月） |
| 买断 | $199.97，3 天退款保证 | 收割"不想再被订阅绑架"心理，边际利润最高 |

**漏斗设计**：40 步 onboarding（问卷 + 依赖测评 + 目标承诺）先让用户完成自我暴露，再进付费墙——沉没成本 + 情绪峰值时刻转化，这是近年心理健康类 App 的标配打法。月/年/买断三档 + 1 天试用 + 3 天退款的组合，是在 App Store 30% 抽成与"性相关应用广告受限"约束下，唯一可靠的变现路径（几乎不可能靠广告）。

**成本侧推断**：iOS/Android/Chrome 三端 + AI 治疗师 + 匿名社区 + 拦截黑名单维护，四人小团队下能撑起这个功能面，说明重度依赖现成基建（订阅走 RevenueCat 类聚合、推送/分析走 Firebase、拦截走 Content Blocker API / 扩展声明式过滤规则），自研的只有课程内容、Streak/游戏化逻辑与 AI 编排层。

## 4. 技术架构推断（外部证据）

- **拦截实现**：iOS 侧只能是 `SFContentBlocker`（正则/域名列表转 compiled rules）+ Safari 扩展；Chrome 侧是 declarativeNetRequest 规则；官方描述"过滤站点与关键词"、无 macOS/Windows 客户端。**没有网络层 DNS 过滤**（否则需要配置文件安装流程，公开教程中未见）。
- **数据面**：隐私政策承认收集邮箱、资料、**习惯日志（streak/relapse）与设备指标**，用 Firebase 做分析，"加密存储"，删除走邮件人工流程——注意：relapse 记录是**服务端存储**而非纯本地，这正是后来泄露事件能发生的根因（详见第 5 节）。
- **Panic Button**：调前置摄像头 + 震动 + 全屏自我凝视界面，纯端侧能力，无需服务端。
- **Melius AI**：对话式治疗师，与本地复刻原型同名同职（工具编排：日记/动力/打卡/游戏唤起）。商照版大概率走第三方 LLM API + 自建 prompt/工具层；对话是否服务端留存未披露。
- **身份体系**：社区匿名（无真实姓名暴露），但账号需邮箱—— pseudonymous 而非 anonymous。

## 5. 安全与信任危机：Firebase 裸奔泄露事件（已核实）

**事件本质**：不是黑客入侵，而是一次经典的 **Firebase 配置错误**——后端数据库允许**未鉴权读取**（无需登录或 API key 即可浏览全部记录；有信源称连写入也开放，该说法佐证较弱）。404 Media 用一个新注册测试账号当场验证了自己的数据出现在暴露数据集中。

**泄露内容与规模**（404 Media 2026-01-28 首发，2026-03-10 病毒式跟进）：
- 数十万用户（次级报道引 60 万+ 记录，其中约 10 万未成年人——此数字出自二手信源，未对照付费墙内原文核实）
- 已证实字段：用户年龄、自慰频率、自述"触发因素"、以及关于**观看什么类型色情内容**的个人忏悔；邮箱/用户名是否泄露未证实
- 结合 App 本身记录 streak/relapse/mood，即每用户一份纵向性行为档案

**回应时间线（这是比泄露本身更难看的部分）**：
- 2025-07-03、2025-08、2025-09 **至少三名独立安全研究者**先后告警，均被无视或否认；联合创始人 Alex Slater 起初称报告是假的/玩笑；有研究者主动提出帮忙修复，无人回复
- 2026-01-28 404 Media 首发报道 → 2026-03-10 跟进报道引爆（r/technology 8.1K 赞）→ 2026-04-06 "黑客警告数月"追踪报道
- Firebase 在 2026-03 病毒式报道前后被封锁，但**至今未见公开事后复盘、正式披露或用户通知**，"已修复"仅见于 404 Media 转述

**商业影响**：截至 2026 年末美区 App Store 仍维持 4.7★（约 3.4 万评分），Google Play 口径 150 万用户——**泄露没有可见地伤害其商业盘**。这构成一个值得警惕的结论：在此类情绪依赖型产品里，羞耻感留存强于信任崩塌流失。

**架构推断更新**：小团队 + Firebase BaaS + 无安全评审 + 无鉴权硬化，与"四人撑起三端全功能"的成本结构完全自洽；自研部分仅游戏化逻辑、课程内容与 AI 编排。

**产品级教训**（与本地复刻原型互证）：
1. 敏感行为数据一旦上云就成为攻击面；复刻原型 `data/quittr-state.json` 全部本地、仅聊天走服务端，是更安全的架构选择。
2. GET 带副作用、无鉴权、CORS 全开这些在本地原型里无害的模式，搬到多用户服务端就是本次级别的事故。
3. 隐私政策"加密存储、邮件删号"的话术与"Firebase 默认规则全开"的现实之间，隔着的只是一次没做的安全配置审查。
4. 漏洞披露响应机制（响应窗口、致谢、复盘）本身就是产品可信度的一部分。

## 6. 增长与品牌策略逆向

- **病毒叙事**：创始人是"两个 20 岁上下英国男生做了个戒色 App"（Alex Slater + Connor McLaren），天然适合 TikTok/播客传播，产品本身（Panic Button 的自拍凝视）也是可演示的短视频素材——**功能即内容**。
- **SEO 对比矩阵**：官网 blog 铺满 `QUITTR vs BlockerX / Fortify / BrainBuddy / Relay / Ever Accountable / Covenant Eyes` 等竞品对比页（自称"honest review"），系统性收割竞品搜索意图。
- **社区留存**：匿名氏族 + 破戒忏悔帖形成情绪闭环，relapse 后用户不敢/不愿离开（羞耻感锚定留存），是此类产品最强也最危险的留存机制。

## 7. 对本地复刻原型（quittr-copy-1）的映射对照

| 商业 Quittr | 本地原型实现 | 保真度 |
|---|---|---|
| Streak + 里程碑 + 90 天目标 | `buildQuittrAnalytics()` relapse 切割重建 + `soberGoalDays:90` | 高 |
| 排名百分位 | `estimateRankPercent()` 五档硬编码假数据 | 形似（商业版有真实用户分布） |
| 社区/Clans | 7 条种子帖子本地 CRUD | 形似（无氏族、无真实多人） |
| 课程教育 | 4 章 20 课 + 本地进度 | 高（内容自制） |
| Panic Button | 前端 `PanicSheet` 组件（无摄像头凝视） | 低（缺自我凝视核心交互） |
| Melius AI | `melius.js` 完整工具编排 + 证据护栏 | 高，且**工程上可能更保守安全**（逐字引用校验、否定正则、幂等重放） |
| 内容拦截器 | JSON 状态机三级锁，无真实拦截 | 形似（原型无 SFContentBlocker/扩展） |
| 付费墙/订阅 | 无 | 缺失（原型无商业化） |
| 40 步 onboarding | 简化 Pledge 弹窗 | 低 |

## 8. 结论

QUITTR 是一个**克制监控、放纵游戏化**的订阅生意：技术上无壁垒（三端皆平台标准能力 + SaaS 基建），壁垒在 40 步 onboarding 到付费墙的转化工程、匿名社区的情绪留存和创始人叙事的分发。它最大的架构决策——把最敏感的 relapse/观看偏好数据放上云——同时也是它最大的一次事故来源。对复刻者而言，本地原型的"数据不出机 + LLM 写操作全证据护栏"路线，恰好修掉了商业版最被诟病的一点。
